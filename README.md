# Anshita Deo — Portfolio

An OS-style portfolio: a Windows 11-style desktop on screens 768px and wider, and a Pixel-style Android (Material You) home screen below that. It shares its layout with the Akshita Deo portfolio, with its own data, teal palette and wallpapers.

## Editing content

All content lives in `src/lib/data.ts`. Derived values such as experience length and organisation count are computed in `src/lib/portfolio.ts`. A field set to `null` (for example `resume`) is hidden in the UI.

- Profile photo: `public/anshita.jpg` (cropped from `design-src/profile-original.jpeg`). After replacing it, regenerate `src/app/icon.png` and `apple-icon.png`, and give it a new filename so the Next image cache picks it up.
- Wallpapers are original art generated by `node design-src/wallpapers.mjs`. `design-src/` is git-ignored.
- Android colours come from `profileData.themeSeed`; Windows colours are the `--win-*` tokens in `src/app/globals.css`.
- The "Highlights" app is the `projects` app id, filled from `projectsData`.

## Develop

```bash
npm install
npm run dev -- -p 3456
```

## Deploy

Deploy on Vercel and set `NEXT_PUBLIC_SITE_URL` to the production domain. `npm run build` must pass before every push.
